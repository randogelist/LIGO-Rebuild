# 08 — GW150914 comparison

## LIGO/GWOSC reference

GWOSC currently lists the GWTC-2.1 preferred source-frame central values for GW150914 as

| Parameter | GWOSC central value |
|---|---:|
| \(m_1\) | 34.6 \(M_\odot\) |
| \(m_2\) | 30.0 \(M_\odot\) |
| total mass | 64.5 \(M_\odot\) |
| chirp mass | 27.9 \(M_\odot\) |
| final mass | 61.5 \(M_\odot\) |
| final spin | 0.68 |
| redshift | 0.10 |

The GW150914 public factsheet gives a remnant ringdown scale of roughly 250 Hz and a damping time of roughly 4 ms.

## Current reduced-model diagnostic

The latest useful L1-only diagnostic sub-fit obtained during this project gave approximately

| Parameter | Reduced-model diagnostic |
|---|---:|
| detector-frame total mass | 70.13 \(M_\odot\) |
| detector-frame chirp mass | 29.44 \(M_\odot\) |
| \(\eta\) | 0.2353 |
| component split | 43.55 + 26.57 \(M_\odot\) |
| final mass | 67.10 \(M_\odot\) |
| final spin | 0.6535 |
| predicted \(f_{220}\) | 248.64 Hz |
| predicted \(\tau_{220}\) | 3.98 ms |

The complete inverse run that produced this diagnostic was **not accepted as a final independent component-mass measurement**, because its early-time holdout was unstable. H1 and L1 themselves agreed much more closely on the bulk scale than the early-vs-full time split did.

## What the reduced model currently distinguishes

The present framework does a reasonable job of recovering or reproducing:

- the overall detector-frame mass scale,
- the chirp-mass scale,
- the remnant-spin scale,
- the dominant ringdown frequency and damping scale.

It does **not yet robustly distinguish the component-mass split** at LIGO parameter-estimation precision.

That is the main unresolved inference direction.
