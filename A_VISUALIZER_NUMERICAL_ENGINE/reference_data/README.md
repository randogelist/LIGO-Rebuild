# GW150914 reference data

The repository does not redistribute the detector reconstruction files. Run:

```powershell
.\download_gw150914_reference.cmd
```

This downloads the public GWOSC P1500229 reconstruction files for H1 and L1:

- `H1_reconstructions.txt`
- `L1_reconstructions.txt`

These are **reference detector reconstructions**, not the induced waveform generated by the visualizer. The visualizer signal and the detector data should be kept conceptually separate.

Public sources:

- https://gwosc.org/GW150914data/P1500229/H1_reconstructions.txt
- https://gwosc.org/GW150914data/P1500229/L1_reconstructions.txt
- https://gwosc.org/events/GW150914/


Note: the top-level README includes a compact waveform illustration. That figure is only a repository overview image; the downloaded H1/L1 files remain the actual public reference waveforms for any data-side comparison.


## Exact experimental vs our fitted waveform

To generate the direct comparison between the **public GWOSC reconstructed signal** and **our current fitted reduced-model waveform**, run:

```powershell
cd A_VISUALIZER_NUMERICAL_ENGINE/reference_data
.\generate_experimental_vs_fit.cmd
```

This will download the public H1/L1 reconstruction files, build a coherent experimental reconstruction, generate the current fitted reduced-model waveform using the accepted BKQR inverse fit parameters, and write:

- `generated/gw150914_experimental_vs_our_fit.csv`
- `generated/gw150914_experimental_vs_our_fit.svg`
- `generated/gw150914_experimental_vs_our_fit.html`
- `generated/gw150914_experimental_vs_our_fit_meta.txt`

The nuisance alignment step only refits a **global amplitude**, **time shift**, and **phase shift** for display. The intrinsic mass/remnant parameters remain fixed to the current fit constants encoded in the script.
