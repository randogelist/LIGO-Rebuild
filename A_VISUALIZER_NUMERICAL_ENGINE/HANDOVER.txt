BKQR_GR_OPTICAL_DYNAMICS_DX12_v1_6_6_2 HANDOVER

BASELINE
--------
Built from the stable v1.4.0.4 DX12 child-window / phase-normalized-view-clock branch.
The v1.4.0.4 crash-hardening remains in place.

WHAT CHANGED
------------
1. Deleted the artificial FLOOR_ORBIT_HOLD merger substitute.
2. Replaced leading quadrupole-only inspiral with a stateful 3PN-energy / 3.5PN-flux TaylorT1-style balance integrator.
3. Replaced the Newtonian J->r0 map with the gauge-invariant 3PN circular angular-momentum relation and deterministic weak-branch inversion.
4. Added explicit E_rad, J_rad, current system mass/J, GW power/J flux, and balance diagnostics.
5. Added NR-calibrated final mass/final spin and dominant Kerr QNM timescale.
6. Added merger/ringdown/remnant stages. The finite-separation ADM and total-J ledgers are preserved by construction.
7. Changed shader protocol to 0x00016000 while preserving the 256-byte constant-buffer ABI.
8. Optical shader now blends moving two-puncture optics into one central remnant and adds non-dynamical GW-power rings to the orbital inset.
9. Default equal-mass J is now 0.9944154929906234, the 3PN circular-J value giving r0=12 M.
10. Added portable energy-balance and merger/remnant regression tests.

DEFAULT PORTABLE AUDIT RESULT
-----------------------------
Default m1=m2=0.5, spins zero:
  r0 = 12 M
  PN switch r ~= 4.263351286 M
  finite-separation initial ADM ~= 0.9904596655 M_rest
  NR-fit final mass ~= 0.9515839429 M_rest
  NR-fit final dimensionless spin ~= 0.6863698794
Portable tests show energy and angular-momentum ledger closure at machine precision and PN balance residual ~1.7e-10 for the default integration.

CLAIM BOUNDARY / NEXT PHYSICS TARGETS
-------------------------------------
This is not full numerical relativity. Strong-field merger geometry is a conservation- and NR-fit-constrained closure, not a solved 3+1 Einstein metric.
For the next fidelity tier:
  A. replace nonspinning PN flux with aligned-spin PN/EOB conservative + dissipative dynamics;
  B. replace Schwarzschild remnant optical propagation with Kerr null-geodesic / frame-dragging propagation;
  C. for actual field-equation convergence through merger, feed the renderer from a BSSN/Z4c/generalized-harmonic NR evolution or an NR surrogate waveform/metric data product.


SOURCE / DETECTOR EXTENSION
---------------------------
11. Added two explicit source-to-detector optical modes:
    * point source -> detector screen
    * cylindrical beam -> detector screen
12. Preserved the 256-byte packet ABI by multiplexing a few packet fields by render mode rather than enlarging the constant buffer.
13. Added backward tracing to a source plane in the HLSL shader (`trace_to_source_plane`) and a dedicated detector shading path (`shade_detector_sample`).

Interpretation: the new detector modes are not a camera looking at the sky. The output image is the detector itself, so bright/dark structures directly show how the black holes lens a source or a beam before it reaches the screen.

DIRECT INITIAL SEPARATION INPUT
-------------------------------
36. Added `Initial separation r0 / M` to PHYSICAL INITIAL CONDITIONS.
37. It is the initial center-to-center object distance, normalized by total mass M.
38. Setting r0/M deterministically rebinds J through the same 3PN circular angular-momentum relation used by the derivation, preserving orbital orientation.
39. J and r0/M therefore remain mutually consistent views of one quasicircular initial condition.
40. Added regression targets `DIRECT_INITIAL_SEPARATION_INPUT`, `INITIAL_SEPARATION_SLIDER_PRESENT`, and `INITIAL_SEPARATION_REBINDS_3PN_J`.
